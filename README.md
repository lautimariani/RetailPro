# Proyecto RetailPro

Repositorio de análisis de datos de ventas minoristas desarrollado para el curso de Data Analytics de Coderhouse.

## Tecnologías utilizadas
* SQL Server Management Studio (SSMS)
* Power Query
* Power BI

## Descripción del proyecto
Este proyecto integra consultas SQL para el análisis de bases de datos de clientes, productos y transacciones comerciales, estructurando vistas y modelos relacionales.
